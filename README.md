# Asistente de Ventas en Tiempo Real

Este repositorio contiene un prototipo inicial para una app web que actúa como asistente de ventas. El sistema escucha la llamada, identifica quién habla y sugiere en tiempo real dos posibles respuestas o acciones para el vendedor. Al finalizar, genera un resumen con puntos clave, objeciones y próximos pasos.

## Estructura
- `app/` Código fuente de la aplicación

## Instrucciones
1. Instala las dependencias con `pip install -r requirements.txt`.
2. Ejecuta `uvicorn app.main:app --reload` para iniciar la aplicación.

# Entrega RedVitalia

Abre `INDEX.html` para revisar visualmente los 24 paquetes y descargarlos uno por uno.

- 24 paquetes ZIP independientes.
- 144 conceptos creativos.
- 1.008 imágenes JPG en siete formatos físicos.
- Briefing, landing, estado e inventario dentro de cada ZIP.
- Hash SHA-256 de cada paquete en `INVENTARIO.csv`.

## Importante

La producción está preparada para revisión, no para publicación automática. Faltan por campaña los datos reales del cliente, brand kit, pruebas autorizadas, privacidad y aprobación humana.
